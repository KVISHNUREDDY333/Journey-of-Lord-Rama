# RAMAYANA: THE EPIC JOURNEY

"RAMAYANA: THE EPIC JOURNEY" is a story-driven, AI-powered adventure game that brings the ancient Indian epic to life through immersive gameplay, dynamic decision-making, and emotionally resonant storytelling.

## 🌟 Vision

Players don't just play the Ramayana—they experience it. The game blends cinematic exploration, tactical combat, and AI-driven dialogues to teach the values of Dharma, loyalty, and courage.

## 🎮 Key Features

- **10 Immersive Levels**: From Ayodhya to Lanka.
- **AI Dialogue System**: Speak dynamically with Rama, Sita, Hanuman, and others.
- **Dharma Decision System**: Your choices shape the emotional narrative.
- **Epic Combat**: Master the divine bow of Lord Rama.
- **Educational Learning**: Summaries and moral insights after every level.

## 🛠️ Technology Stack

- **Frontend**: HTML5 Canvas, Vanilla Javascript (ES6+), CSS3.
- **Backend**: FastAPI (Python), MongoDB.
- **AI Engine**: Google Gemini / Groq for dynamic NPC behavior and storytelling.

## 🚀 Getting Started

1. **Backend**:

   ```bash
   cd server
   pip install -r requirements.txt
   uvicorn app.main:app --reload
   ```

2. **Frontend**:

   Open `client/index.html` in your browser or serve it via a local static server.
